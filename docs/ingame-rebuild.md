# インゲーム再構築 — 異能決闘卓

調査・実装日: 2026-11-24。ローカル実装。人物は既存の画像・切り抜き設定を再使用し、生成画像への差し替えは行わない。

## 方向と実装

「牌で戦う異能バトル」を主軸に、墨藍の布、黒い厚縁、白磁調の牌、朱の操作・能力アクセントを組み合わせる。
通常の一打が気持ちよく、相棒と同じ場所にいることを優先する。派手な演出は能力・和了など意味のある出来事に対応させる。

- `src/ui/duel.css`: インゲームに限定した色・書体・席HP・相棒・下端の操作帯。メニューには適用しない。
- `src/ui/canvasRenderer.js`: 既存CC0牌面を維持した二層の側面、面取り、接地影、青磁色の背、卓の象嵌、局情報。手牌から河への210msの打牌移動。描画だけで状態進行を止めない。
- `src/ui/duelPresentation.js`: 通常2/3/4人戦で実際のHP行を席の近くに置く。従来のHP精算保留・残像・順位表示を再利用。団体/ペアは控えメンバーなどの情報量を維持するため右のチームボードを残す。
- 人物: `fillPortrait` / `CharacterImages` と既存の画像・切り抜き設定を継続。新しい立ち絵やポーズを生成しない。
- 能力: 発動中に卓の縁が反応。既存の能力カットイン、牌のリング、キャラクター反応を継続。
- `prefers-reduced-motion`: 新しい移動を省略し、DOM演出も短縮。

## 文字設計の根拠

| 原則 | 一次資料 | 今回の設計への反映 |
|---|---|---|
| 階層、近接、整列、反復、余白 | [Adobe: Graphic design](https://www.adobe.com/uk/creativecloud/design/discover/what-is-graphic-design.html) | 牌を主役に、名前とHPを席にまとめる。点数の右端を揃え、操作は下端の一帯に集約。 |

| 和文のベタ組・禁則 | [W3C: 日本語組版処理の要件](https://www.w3.org/TR/jlreq/) | セリフは字間0、行高1.65、左揃え、strict禁則。短い見出しだけ控えめに字間を取る。 |
| 通常文字4.5:1、大文字3:1 | [WCAG 2.2: Contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) | 主要文字は明るい白磁色＋安定した濃紺下地。キャラ色を主要な名前の文字色にしない。状態は「手番」「リーチ」等の文字も併用。 |

書体は役割ごとに2系統、常用ウェイトは400/500/600。枠線・グローで全てを強調せず、字級差と余白で階層を作る。
席の風・手番などの短い補助表示には12–14pxも使用する。1280×720ステージ全体を小画面で縮小する既存方式のため、論理16pxが常に画面上16 CSS pxになるわけではない。WCAG全体適合を主張するものではない。

### 配布・保守

- フォントの著作権とOFL: `graphic/fonts/*-OFL.txt`。WOFF2への形式変換で著作権表示を落とさない。
- 布の出典: `graphic/materials/README.md`。人物・購入済み素材の元ファイルは変更しない。
- 新たな外部CDN依存はない。CSS、フォント、布は同一オリジンから配信する。
- 既存有料UIセットをインゲームの全面枠として再利用すると旧画面の印象が残るため、今回は線・余白・字級によるCSSの意匠を採用。
- 空想曲線の規約は2026-11-06更新でAIコーディング支援の許可範囲を明記。既存の画像を新たな生成画像・動画の参照にしない運用を継続する。

### 副露とHPの重なり修正

- 対面の副露が旧配置（卓の左上）に残っており、上家のHP表示の裏に隠れるケースを再現。対面の手牌と副露を同じ上辺の列にまとめた。大会の増減表示でHP枠が広がる場合も避ける。
- **副露数による自動縮小は廃止**。相手の副露は全席で一定の倍率0.68（以前の通常時0.62より約10%拡大）。左右は4カンでも一列に並び、鳴いた牌の方向を維持する。
- 相手のHPを卓より上の高さ128pxに揃え、左右の辺に500px分の副露用スペースを確保。手前の手牌・卓の縁・操作帯を6px下へ調整し、牌の厚みも含めて接触を避ける。伏せ牌との間隔も確保。
- 既存人物絵を上部の席に配置し直し、設定・オート・鳴きなしを右上へ集約。「手番」は全席でHP枠内へ移動。共闘ボードは操作ボタンより下へ配置し、必要な分を内部でスクロールする。
- `node test/duel-meld-layout.mjs`: 800配置通過。2/3/4人、席順、鳴いた相手の方向、1〜4組のチー・ポン・明槓・暗槓・加槓を確認。実際のCanvas描画位置を傾斜後の座標へ変換して、HP・共闘用名札・手牌・河との交差を検出する。牌の描画サイズが席・副露数・種類で縮小されないことも検査。従来の描画228チェックも通過。
- ブラウザ検証用: `/test/fixtures/meld-visibility.html`。本体のRendererとCSSを利用した表示専用ページ。各席の最大配置を同時に並べる限界確認であり、実際の一局を表すものではない。1280×720と960×540で確認。
- [縮小しない最大副露の確認画像](previews/meld-readable.jpg)。人物画像のファイル・ルール・鳴く方向の表現は変更していない。
- 実ブラウザでは通常4人戦、ペア戦の方針パネル、移動した設定・オート・能力操作、手牌の選択も確認。通常対局で相手の実際のポンも表示。1280×720と960×540で検証し、コンソールのerrorなし。
