# ツモノグリフ テストプレイのご案内

遊んでくれてありがとうございます。
これは開発中のブラウザゲーム **「ツモノグリフ 〜牌と絆のアンサンブル〜」** のテスト版です。

**持ち点＝HP** の麻雀に、キャラクターの能力と物語を乗せた作品です。
ひとりで打つ麻雀を「相棒と一緒に戦うもの」に変えられているか——そこがいちばん知りたいところです。

---

## 1. 遊びかた

**URL**: https://migratory-studio.github.io/Marjong/

| | |
|---|---|
| 推奨ブラウザ | **Google Chrome（PC）** |
| 推奨環境 | PC・横画面。画面は自動で拡大縮小します |
| スマホ・タブレット | 一応動きますが **横向き必須**（縦だと画面が回転して表示されます） |
| インストール | 不要。URLを開くだけです |
| セーブ | 自動。ブラウザに保存されます（Googleログインするとクラウドにも） |

麻雀のルールは知らなくても大丈夫です（役や点数は自動で計算されます）。
牌を切るときは **①牌をタップして選ぶ → ②もう一度タップして確定** の2タップです。

## 2. 何を試してほしいか

全部やる必要はありません。**30分でも十分**です。気になったところだけ触ってください。

### まずはここ（30分コース）
1. **対戦ホーム** … 出迎えてくれるキャラがいます。話しかけてみてください
2. **フリー対戦 → 🎲 おまかせで即対局** … 1半荘打ってみる
3. 打ちながら、**右側の相棒ボード**（HPバーとキャラの一言）を気にしてみてください
4. 対局が終わったら **対戦ホームへ戻る** … 何か変わっていますか？

### 時間があれば
- **師弟モード** … マイキャラを作って師匠に弟子入り。物語が進みます
- **楼光の館** … 3人パーティで塔をどこまで潜れるかのローグライト
- **オンライン対戦** … 現在は限定運用です（別途ご案内します）

### 特に聞きたいこと
- キャラクターを **好きになれそうか**。誰が気になりましたか？
- 点棒が減る/増えることが **「痛い/嬉しい」** と感じられたか
- どこで **迷ったか・詰まったか**（「何をすればいいか分からない」瞬間）
- どこで **やめたくなったか**（正直に教えてください。いちばん大事な情報です）

## 3. 既知の未実装（バグではありません）

以下は「まだ作っていない」ところです。報告いただかなくて大丈夫です。

- 一部のキャラ・師匠は **「準備中」** 表示です（順に実装中）
- **楼光の館は第2章まで**。その先は「未だ綴られぬ記憶」と出ます
- 紙芝居の一部SEが無音・**立ち絵の表情差分は未対応**です
- **タイトルロゴと楼光の館の一部グラフィックは仮素材**（正式版に差し替え予定）
- **オンライン対戦は限定運用**です（合言葉ルームでの対戦を推奨）
- スマートフォンは横向き推奨。縦のままだと画面が回転して表示されます

## 4. 不具合・感想の送りかた

**ゲーム内: 設定 → 「テスト版について / 不具合を報告」** から送れます。

1. 上記のボタンで窓口を開く
2. **「環境情報をコピー」** を押す（バージョンやブラウザ情報が入ります）
3. コピーした内容と一緒に、下記の連絡先へ送ってください

> **報告フォーム**: https://docs.google.com/forms/d/e/1FAIpQLSeP18R5mRn-TbYFhL4NVbQIboMGjtH4Ccr09bjirFkHqlJq2g/viewform
>
> ゲーム内の「テスト版について / 不具合を報告」→「報告フォームを開く」からも直接開けます。
> Google アカウントへのログインは不要です。

書いてくれると助かること:

- **何をしていたら**そうなったか（例: 師弟モードの3日目、対局中にポンした直後）
- 画面の写真（スクリーンショット）があると一発で分かります
- 「バグ」でなくても大歓迎です。**「ここが分かりにくい」「ここが退屈」** がいちばん役に立ちます

ゲームが固まった・エラーが出た場合は、画面右下に小さく通知が出ます。
その **「報告する」** を押すと、同じ窓口が開きます（直前のエラー内容が環境情報に入ります）。

## 5. セーブデータについて

- データは **お使いのブラウザに保存** されます。ブラウザの履歴やサイトデータを消すと、進行も消えます
- **Googleログイン**（任意）をすると、クラウドにも保存され、別の端末から続けられます
- **テスト期間中は、更新によってデータが壊れる/リセットが必要になる場合があります**。ご容赦ください
- 最初からやり直したいときは **設定 → 「セーブデータを初期化」** から消せます

### 集めている情報について

- ログインしない場合、こちらに送られる個人情報はありません（データはブラウザの中だけ）
- Googleログインをした場合、アカウントのメールアドレスと、ゲームの進行データが保存されます
- 不具合報告の「環境情報」に入るのは、バージョン・ブラウザ・画面サイズ・進行の概数だけです
  （メールアドレスや表示名は入りません。コピー前に中身を確認できます）
