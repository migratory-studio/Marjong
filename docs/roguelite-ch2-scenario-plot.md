## 0. テーマの核＝「賭け方の三様」と「読ませない者たち」

**キャスト3人は全員 role=gambler**。賭けるものが三様に違う：

| | 賭けるもの | 正典の芯 |
|---|---|---|
| 焔 | **炎**（打点の生き様。満貫未満は認めない） | 1巡目に全てを賭ける。燃え盛るか、火が萎むか |
| ルイナ | **点棒＝命**（運命に張る） | 素性・種は一切不明。「いい目だ」で目が転ぶ伝説 |
| ドラニエル | **目そのもの**（ドラを自分で吊り上げる） | 紙HP承知の一発逆転。自称天使・真偽は余白 |

そして楼光を登るプレイヤー自身が、点棒＝HP＝命を賭けて登る**四人目の「炎を賭す者」**である
（点棒=HPのメカがそのまま章題に接続する）。

もう一つの核：ルイナ（種明かしNG）とドラニエル（天使真偽は余白）は**素性を明かさないことが正典**、
焔は**まだ何も彫られていない**（bio2行のみ）。つまり「記憶を映す塔」に、記憶を読ませない者たちが
立っている——この矛盾を隠さず、章の問いにする。秘密は一切明かさない。

大1章との対比（章スケールの縦軸）：

| | 大1章「還らぬ師の記憶」 | 大2章「炎を賭す者たちの記憶」 |
|---|---|---|
| 記憶の質 | すべての記憶に「見ていた師」がいた | **誰にも見られなかった記憶**（系譜の外） |
| 顔 | 群像の顔が鮮やか | 門番に顔がない（＝モブのシルエット基盤がそのまま演出） |
| 答え | 塔に残っていたのは師のまなざし | **火は、配っても減らない**（他者の記憶に住む） |
| プレイヤーへの反転 | あなたは**待たれていた**（空席） | あなたは**語られはじめている**（覚えられていく） |
| tone | gold（温かさと喪失） | **ash 維持**＝灰。意味を再定義：「賭けて燃え尽きた者たちの層。その下で熾きる火」 |

## 1. 章の問いと答え（縦軸の芯）

- **章の問い**：賭けて燃え尽きた者たちの炎は、どこへ行くのか。——見る者のいなかった炎を、誰が覚えているのか。
  - 大1章で「記憶には、見ていた誰かがいる」と学んだ直後だからこそ立つ問い。
  - この層の記憶には**顔がない**。賭場の夜、路地裏の卓——賭けて、燃え尽きて、誰にも見られなかった者たち＝灰。
- **中間の答え・その一（F30＝焔）**：**燃えてりゃ、周りの顔が見える**。
  焔の卓の記憶だけ、灰の層の中で顔が照らされている。見る者がいなくても燃える——燃えれば、照らせる。
  （熱血の現在形の答え。だがまだ「その火自体を誰が覚えるのか」は残る＝F40への階段）
- **中間の確信（F20〜F30）**：ドラニエルの天界視点による観測——「この層の夜は、**天界の帳面にも無い**」。
  誰も見ていない、天すら見ていない。そして層の奥に、ひとつだけ「大きすぎる火」の噂：紫の女。
  塔のどこにも彼女自身の記憶はなく、**彼女に負けた夜の記憶だけが、無数にある**。
- **答え（F40のペイオフ）**：ルイナは記憶を「持たない」のではなく「**配って歩く**」。
  負けた夜は一生もの——名もなき者たちはみな、彼女と打った一晩だけは顔を上げて語る。
  **火は、配っても減らない。** 伝説とは、自らの記憶を持たず、他者の記憶に住む者のこと。
- **反転（プレイヤーへ）**：読む側のつもりで登ってきたあなたは、**綴られる側になっていた**。
  あなたが越えてきた顔のない門番たち——彼らはあなたとの一局だけは、顔つきで覚えて帰っている。
  あなたの炎も、もう配られはじめている。大1章「待たれていた」→大2章「**語られはじめている**」。
  （実装済みの「ボスが覚えている」bossTally 機構が、このテーマのメカ的裏打ちとしてそのまま効く）
- **タイトル回収**：「炎を賭す者たち」＝灰の門番も、焔も、ルイナも、ドラニエルも——そして点棒（＝命）を
  賭けて楼光を登る、あなたも。
- **やらないこと（各正典NGの完全遵守・最重要）**：
  - ルイナの素性・種・弱みには**一切**触れない。F40のルイナは「他者の記憶から編まれた像」として
    扱い、本人の内面に踏み込まない（大1章の詩玥サンプル「記憶の我は本物より意地悪カモ」と同じ装置）。
  - **口癖の反転は使わない**。『いい目だ』→『いい目に、する』はルイナ編ep20、『下界の麻雀は最高じゃのう』
    の反転はドラニエル編ep20の**切り札＝予約済み**。楼光では口癖を**そのまま**使う。
    章スケールの反転は「読む側→綴られる側」で打つ（キャラの反転と競合しない）。
  - **焔は盛らない**：正典が薄いキャラに楼光で背骨を生やさない。本章で確定してよい追加は
    **①打ち方は誰にも習っていない（独学＝灯を継がぬ側） ②ルイナに負けた夜が一度ある
    （噂の正典『賭羽ルイナに勝った者はいない』と整合）** の2点まで。口癖の新設・過去・出自の発明は禁止。
    口調は確定済みの熱血「俺」。
  - ドラニエルの天使設定は与太のまま（天界視点の観測は「本人がそう言っている」の域を出ない・真偽断定は不可）。
  - 先代・師の系譜は出さない（大1章の領分）。対比は地の文一行まで。
  - 各師匠編の固有イベント（ep番号もの）を再演・先取りしない。時系列も確定しない
    （楼光は記憶の塔＝「いつの彼らか」を固定しない書き方）。

## 2. 紙芝居ビート設計（4本・F10/F20/F30/F40 初踏破）

大1章と同じ器（`rogueliteBeatMaster.js`・初回のみ・既読永続・話者は章cast＋地の文・
「いま倒した相手」を名指ししない・背景は実リソースのみ）。4本で「違和感→確信→火の答え→配る者の答え＋反転」の階段。
背景は全て実在ID：bg-bar（賭場の夜）／bg-rain（雨の路地裏＝大1章B1と同じ雨色グラデ）／bg-festival（焔の卓）／黒。
※実機確認（2026-07-10）：みんちりえ屋外系（street/city/festival/arcade）は**昼の画像**のため、夜の場は
bg-rain・bg-bar・黒で受ける。bg-festival の昼の明るさは「灰の層で焔の卓だけ真昼のように明るい」＝
火の誇張表現として**意図的に**使う（素材制約をテーマに回収）。

### B1「顔のない夜」— F10 初踏破後

- **役割**：①章の問いの提示（顔のない記憶＝灰） ②大1章との対比を一行 ③ドラニエル登場（狂言回し）。
- **流れ（たたき）**：
  1. 地の文：扉が開く。流れ込む記憶——夜の賭場。卓を囲む影、牌の音、笑い声。だが、どの顔も灰を被ったように暗い。
  2. 地の文：第一の記憶では、誰の顔も鮮やかだった。……見ていた誰かが、いたからだ。
  3. ドラニエル「おかしいのじゃ。下界の卓は、もっと顔がうるさいはずじゃぞ？」
  4. ドラニエル「……ふむ、わかったのじゃ。ここは、誰にも見られておらんかった記憶の層じゃ。見る者のおらん記憶は、顔から先に灰になる」
  5. ドラニエル「じゃがのう——耳を澄ませてみよ。灰の下で、牌の音だけは、まだ熾きておる」
  6. 地の文：賭けて、燃え尽きて、誰にも語られなかった夜が、幾重にも積もっている。この塔の、誰も読まなかった頁。
- **キーライン**：「見る者のおらん記憶は、顔から先に灰になる」

### B2「天界の帳面」— F20 初踏破後

- **役割**：①問いの確信（誰も見ていない・**天すら見ていない**） ②F30への引き（燃えたままの火がひとつ）。
- **流れ（たたき）**：
  1. 地の文：記憶——雨の路地裏の卓。無言で打ち続ける影たち。ここにも、顔はない。
  2. ドラニエル「わらわ、天界におった頃は、下界の卓がぜんぶ見えておったのじゃ。……じゃがな、この層の夜は——**天界の帳面にも、無い**」
  3. ドラニエル「誰も見ておらん。天も見ておらん。そういう夜が、こんなに積もっておったとはのう……」
  4. 地の文：積もった灰の、ずっと奥。——ひとつだけ、火の色が見える。
  5. ドラニエル「……おかしいのじゃ。灰の層のくせに、あそこだけ**燃えたまま**じゃぞ？」
  6. 地の文：誰にも見られないまま、燃え続けている火が——この先に、いる。
- **キーライン**：「天界の帳面にも、無い」（天使の真偽は与太のまま＝本人がそう言っているだけ、の域を守る）

### B3「燃えたまま」— F30 初踏破後（焔の門の奥）

- **役割**：①火の答え（燃えれば照らせる＝灰にならない生き方） ②灯を継がぬ側の確認（独学）
  ③ルイナの前振り（賭けても減らない火）。
- **流れ（たたき）**：
  1. 地の文：扉の奥——賑わう露店通り。この灰の層で、ここだけが——真昼のように、明るい。
  2. 地の文：卓を囲む顔が、見える。灰の層で初めて見る、名もなき者たちの顔。——火が、照らしている。
  3. 焔「よう。辛気くせえ層だろ、ここは。……だから俺は燃やしてんだよ。毎晩な」
  4. 焔「見てるやつがいなきゃ燃えねえのかって？　逆だろ。**燃えてりゃ、周りの顔が見えるんだ**。俺の卓は、いつだって明るかったぜ」
  5. ドラニエル「ふぉっふぉ、豪気なやつじゃのう！　じゃがぬし、その燃え方——誰に習うた？」
  6. 焔「習っちゃいねえよ、誰にもな。……ただ一晩だけ、**でかすぎる火**を見たことがある。——紫の、女だ」
  7. 地の文：その名を、この層の誰もが知っていた。自分の顔は忘れられても、あの女に負けた夜だけは、誰もが語れる。
  8. 焔「俺もあの夜は取り返せてねえ。……先へ行くなら教えといてやる。**あの火は、賭けても減らねえぞ**」
- **キーライン**：「燃えてりゃ、周りの顔が見える」／「あの火は、賭けても減らねえ」
- ※焔の追加設定はここで確定する2点（独学・ルイナに負けた夜）のみ。それ以上は彫らない。

### B4「配られた夜」— F40 初踏破＝章踏破（踏破演出の前に再生・大1章B3と同型）

- **役割**：①答え（配って歩く側＝火は配っても減らない） ②プレイヤーへの反転（綴られる側） ③踏破演出へ接続。
- **流れ（たたき）**：
  1. 地の文：最後の扉。この先に、彼女の記憶があるはずだった。
  2. 地の文：——開く。部屋はひとつではない。無数の夜の断片。全部、違う誰かの目で見た、同じ女。
  3. ルイナ「……おや。あたしの底を覗きに来たのかい。いい度胸だ」
  4. ドラニエル「ルイナ。ぬし、記憶を持っておらんのか？」
  5. ルイナ「持たないのさ。あたしは**配って歩く側**でね。——負けた夜ってのは、一生ものだろう？　みんな、大事に持って帰るのさ」
  6. ドラニエル「……わかったのじゃ。下の兄ちゃんが言うておった、賭けても減らぬ火——**配っても、減らぬのじゃな**」
  7. ルイナ「あたりまえさ。**火ってのは、そういうものだよ**」
  8. ルイナ「ふふ。……ところで、あんた」
  9. ルイナ「気づいてるかい。この塔であんたが越えてきた、顔のない連中——**あんたとの一局だけは、顔つきで覚えて帰ってる**」
  10. 地の文：思い返す。幾つもの夜、幾つもの卓。読む側のつもりで、登ってきた。——綴られる側に、なっていた。
  11. ドラニエル「ふぉっふぉ、よい夜じゃったのう！　下界の麻雀は、最高じゃのう！」※口癖はそのまま（反転はドラニエル編の切り札＝使わない）
  12. ルイナ「……いい目だ。また張りにおいで。**次はあんたの夜を、誰かが語る番さ**」※同じく口癖はそのまま
  13. →既存の踏破演出（「踏 破」印）へ。
- **キーライン**：「火は、配っても減らない」／「次はあんたの夜を、誰かが語る番さ」
- ※B3の焔「賭けても減らねえ」→B4「配っても減らぬ」の脚韻で、焔の答えをルイナの答えが引き取る。
