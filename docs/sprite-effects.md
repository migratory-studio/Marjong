規約：https://kopacurve.blog.fc2.com/blog-entry-394.html （2026-10-09 確認。UI一式・エモートと同じ配布元＝CREDITS.md「こぱんだ屋」節）

| 規約 | この実装での扱い |
|---|---|
| ゲーム（ブラウザゲーム）での利用 | 可（作者回答）。有料素材なので**クレジット表記は不要**（CREDITS.md には記録として載せる） |
| 素材をそのままの状態で配布・販売するのは禁止 | 原本は `_assets-stock/effects/kuusou-kyokusen_gameeffect01_192/`（`.gitignore`＝**リポジトリに載せない**）。ゲームに載せるのは**使う色違いだけを1枚のアトラスに組み直した `graphic/fx/*.avif`**（41枚・約5.9MB） |
| 加工（サイズ・色・形式の変更、一部の切り取り） | 可。アトラス化・AVIF化・表示サイズの拡縮はこの範囲 |
| **生成AI・機械学習での学習／解析への使用は禁止** | **画像そのものを AI（Claude）に見せていない**。選定は名前・コマ数と、色違いの「色の名前」だけで行った。色の名前は `node tools/build-effects.mjs survey`（画素の色相を数えるだけの決まった計算・機械学習ではない）で出した。動作確認も「枠だけ」表示（後述 `window.__fxWire`）で位置と尺だけを見た |

- リポジトリが public の間は「ZIP一括DL」の問題が他の購入素材と同じく残る。CREDITS.md「配布方針」の **private 化で一緒に塞がる**（アトラスも他素材と同じ扱い）。

## 1. 物差し

1. **点棒＝HP を、手応えにする。** 点が動く瞬間に「当たった／回復した」が身体で分かる。被弾＝打撃、和了＝回復、トビ＝白い衝撃。
2. **色＝誰の一撃か。** 和了・リーチ・カンは**打った人のキャラ色**の色違いで響く（詩玥＝赤、ルクス＝青、凌雲＝黄…）。対戦相手の印象が「立ち絵と名前」から「あの青い波紋」へ育つ（固有性）。
3. **能力＝そのキャラの視界を一局だけ貸す**（character-ingame-fx-plan の物差しのまま）。発動の瞬間と、**能力が効いた瞬間**に、そのキャラだけの絵を置く。
4. **テンポを殺さない。** 進行は一切待たない（重ねるだけ）。頻度の高い瞬間（ポン・チー・毎ツモ）には付けない。

### 2-3. あえて付けなかったところ

- **ポン・チー**（頻度が高い＝テロップだけで十分）、**毎ツモ**（詩玥の金リングなど CSS の小FXが既にある）。
- **ピンチ突入**（HP25%以下）：素が滲む瞬間（CLAUDE.md ピラー4）を、めまい等で茶化さない。卓の縁の赤と心音のまま。
- 使っていない種類：銃撃（単発・連射）＝麻雀の語彙に合わない／X斬り・乱れ斬り・めまい_シングル＝役割が重なる。色違いを足すのと同じ手順でいつでも足せる。

## 3. 仕組み（どこに何があるか）

| もの | 場所 |
|---|---|
| 選定表（いつ・どれを・何色で・大きさ） | `src/data/effectMaster.js` の `FX_CUES`（共通）と `ABILITY_FX`（能力ごと）。台帳 `FX_TYPES`（種類→原本番号・コマ数・載せる色違い） |
| コマ送り | `src/ui/spriteFx.js`（`playFx` / `preloadFx`）。1つの rAF で全部を進め、コマは「経過時間×24fps」＝処理落ちしても尺は原本どおり。初回で読み込みが間に合わなければ少しだけ待ち、来なければその回は出さない |
| どこに出すか | `src/main.js` の `fxAtSeat`（席）/ `fxAtTable`・`fxAtHandTile`・`fxAtRiverTile`（卓・牌）/ `fxOnEl`（行・立ち絵・パネル）/ `playAbilityCastFx`（カットイン）/ `dmgRowFx`・`hpBoardFx`・`portraitHitFx`（点棒＝HP） |
| 卓の上の層 | `index.html` の `#sprite-fx`（`#naki-fx` と同じ z で DOM が前＝席テロップの文字を隠さない） |
| アトラスの書き出し | `node tools/build-effects.mjs`（原本 → `graphic/fx/<種類>-<色>.avif`、1マス200px＝192pxのコマ＋4pxの透明な余白、横 frames/4 × 縦4）。形式は AVIF（品質60）：パレットPNGの約半分の容量で、暗い卓の上の誤差は 40dB 前後 |
| 色違いの一覧 | `node tools/build-effects.mjs survey`（01=赤 02=黄橙 03=緑 04=青 05=紫 06=桃/白系 07=白。炎は 01=橙 02=黄緑 03=青 04=紫、ハートは 01=桃 02=黄 03=水色 04=紫） |
| キャラ色 → 色違い | `colorKeyOf(hex)`（色相で red/yellow/green/blue/purple/pink、彩度の低い灰色は white）。その種類に無い色は近い色へ寄せる（例：白い波紋は無いので灰色のキャラは青） |
| 先読み | `beginGame` → `preloadMatchFx()`：卓に着くキャラ全員ぶん（団体戦の控え・ペア戦の4人も）。低優先度。`lazy` のキュー（役満の閃光・絆のハート・表に無い能力）は先読みしない |
| 回帰テスト | `node test/spritefx.mjs`（台帳の形・アトラスの実在と寸法・キューの参照先・**キャラを足したときの抜け**・全キャラの色・先読み） |
| デバッグ | `?debug=tsumoreba` → 🐛 →「スプライト演出」で単体再生（キャラ選択で色が変わる）。「枠だけ」＝`window.__fxWire = true`（素材を描かず枠と名前・コマ番号だけ）。`window.__fxLog` に再生の記録（直近200件） |

### 対人戦（docs/character-ingame-fx-plan.md §7 の3ルール）

- ロン・ツモ・リーチ・カン・被ダメ・守り・呪いは**公開情報**（イベントと `lastResult`）から出す＝全員に同じものが出る。
- 能力の発動は能力カットインと同じ `abilityUsed`（abilityId と対象の席だけ＝秘匿 params は使わない）。
- 真守の「通した」は**自席の危険度**（権威が自席にだけ送る `danger`）で判定＝ルール1（自席の情報だけで描ける）。
- ルクスの捕捉・確保、RE の交換、カリュブディスの呑まれた和了牌は、もとの CSS 演出と同じく自席の操作・自席の手牌にだけ出る。

## 4. 変え方

- **色を変える**：`FX_TYPES.<種類>.variants` の番号を `survey` の一覧から選び直す → `node tools/build-effects.mjs` → `node test/spritefx.mjs`。キューの `color` は「色の系統」なので、そのままでよい。
- **別のエフェクトにする・大きさ／速さ**：`FX_CUES` / `ABILITY_FX` の `fx` / `size` / `speed` / `delay` を書き換える（新しい種類・色なら `FX_TYPES` に足してビルド）。
- **新しいキャラ**：`ABILITY_FX` に1行（手動能力なら `cast`、和了点を動かすなら `scoreUp/scoreDown`、守り・呪いなら `guard/curse`）。足し忘れは `test/spritefx.mjs` が落ちる。効いた瞬間の位置が新しいなら `main.js` に呼び出しを1行。

## 5. 確認したこと（2026-10-10）

ヘッドレス Chrome（1280×720）で実際に対局を回し、`window.__fxLog`（どの演出がどの要素に出たか）・コンソールエラー・`__mjErrLog` を見た。
位置は「枠だけ」表示（`window.__fxWire`）のスクリーンショットで確認した（**素材の絵は見ていない**）。進行のタイマーだけ検証用に速めた（演出のコマ送りは実時間）。

| モード | 結果 |
|---|---|
| フリー 4人（16キャラ全員を操作キャラで1局ずつ・自動対局） | エラー 0。リーチの波紋・ロンの衝撃がキャラ色ごとに出る（赤・黄・緑・青・紫・桃・白）。ダメージカードの打撃／連打／回復／撃沈、HPボードの打撃／回復、相棒の立ち絵への打撃 |
| フリー 4人（能力ボタンを実際に押して操作・10キャラ） | ルクスの捕捉→確保、RE の交換の両端、ルイナの「張る」「灰」「配当」、ドラニエルの新ドラの閃光と「天啓」、焔の発動と「火が萎んだ」、春嬋の「疾走」と聴牌の一閃、真守の「赤を通した」結界、凌雲の盾が剥がれる瞬間と受け止めた行、蓮の「咲く／沈む」、ネビュラの呪われた行と「半分」 |
| フリー 3人・2人（二人麻雀） | エラー 0（席の割り当て 3人=自/右/左、2人=自/対面で正しい位置） |
| 団体戦・ペア戦 | エラー 0。団体・ペアのダメージ行（名前の位置）に打撃・撃沈。和了者の行は HP が増えないので回復は出さない |
| 楼光の館 | エラー 0。モブ（灰色）は白系の色に寄る |
| 対人（ループバック） | エラー 0。相手の能力発動・リーチ・カン・ロン・被ダメ・トビ |
| 師弟（二人打ち・本気で打つ） | エラー 0。弟子の色（黄）と師匠の色（赤）で分かれる |
| デバッグメニュー | 役満（衝撃波＋閃光が立ち絵と大書きの奥）・満貫（「ロン／ツモ」の文字の真後ろに稲妻）・能力の発動（立ち絵の上半身） |

- 回帰テスト：`node test/spritefx.mjs` ALL PASS。既存の scorefx / ambershield / nebula / betlost / eventlog / netredact / muddylotus / dorapull / modelanswer / voicepri も PASS。
- 実戦で起きるのを待てず**コードと同じ経路の確認に留めたもの**：役満（デバッグメニューで再生）、絆のハート（ログイン時のみ出る）、焔の火柱・「焔が舐めた」、ドラニエルの背水の天啓、姚玖の満月、蓮の水位が引く瞬間（超越帯）、ビビの超越帯、凌雲の盾の編み直し（超越帯）、カリュブディスの呑まれた和了牌（既存の CSS 演出 `fx-abyss` と同じ箇所から呼ぶ）。
