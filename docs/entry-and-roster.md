# タイトルから着席までの画面設計

ツモノグリフには通常の雀士が16人いる。最初から選べるのは13人で、通常のフリー対戦と楼光の館には、修行を終えた弟子が最大5人加わる。初めて遊ぶ人は顔と固有能力から、目当ての雀士がいる人は名前や読みから同じ名簿を使えるようにした。

## タイトルと対局準備

タイトルは、左に題字と「はじめる」、右に雀荘で出迎える二人の全身立ち絵を配置した。名前を足元に添え、初対面の雀士も後から指名できる。二人の組み合わせは起動ごとに変わる。音量やセーブデータを扱う設定は、タイトルと相棒ホームの両方から開ける。[タイトルの実画面](previews/title-entry.jpg)

フリー対戦は「対戦形式 → 卓 → キャラ選択 → ルール・確認」の順。個人戦は牌、ペア戦は二人、団体戦は三人の絵札で見分けられる。卓の段階で何席を決めるのかが見え、人数や形式は上の見出しから戻って変えられる。すぐに打ちたいときは形式選択の「おまかせで即対局」から四人東風戦へ進める。

## 多人数の名簿でできること

| プレイヤーがしたいこと | 画面での操作 |
| --- | --- |
| 顔を見ながら好きなキャラを探す | 4列×2段の顔札をめくる。全員解禁で2ページ、弟子5人を含む21人でも3ページ。名前の位置と顔札の大きさは同じ。 |
| 知っているキャラにすぐ会う | 名前・読み・固有能力名で検索。「ｼﾕｴ」「しゆえ」「ツモれば勝ち」のいずれでも詩玥を探せる。役割との併用もできる。 |
| どう打つキャラか知る | 顔札を押すと左の人物欄がその場で切り替わる。開始HPと能力の効果を読み、「人物・能力値」で攻め・守り・癖・難易度を見られる。 |
| 選んだメンバーを保ってほかの候補を見る | 席は上段に常時表示。札の「候補」は閲覧中の人物、「あなた」「CPU①」などは確定した席を示す。着席ボタンには次に誰の席を決めるかが出る。 |
| 未解禁のキャラも調べる | フリー対戦と楼光は解禁済みから始まる。「解禁済みのみ」を外すと、未解禁の能力や解禁先を確認できる。未解禁のキャラの確定ボタンは無効。 |
| タッチやキーボードで選ぶ | タップで詳細を開く。キーボードではTabで名簿に入り、矢印で顔を移動してEnterで選ぶ。該当者がゼロなら同じ場所から絞り込みを解除できる。 |

フリー対戦では一人決めると次の空席へ移る。席を決めた直後の連打で、その雀士を次の席へ移すことはない。通常戦のCPUとペア戦の相方はおまかせを選べる。団体戦は自チームの3人が揃うと対局を開始できる。[キャラ選択の実画面](previews/character-select.jpg)

## 選ぶ目的に合わせた画面

| 画面 | 選び方と判断材料 |
| --- | --- |
| 相棒ホーム | 今の相棒がいるページで開き、顔札を一度押すとその場で交代。背景を替えると、新しい風景の中に相棒が立つ。 |
| 楼光の館 | 「あなた」「相棒」「控え」の席順、出発HP、絆を見ながら1〜3人を編成する。外すときは出発メンバーの「×」を押すと、後ろの人が繰り上がる。 |
| 通信対戦 | 戦績または四つの席を左に、名簿を右に表示。ページを移っても自分の雀士の名前が残る。ルームでは届いた席情報に合わせて表示を更新し、操作中の検索条件を保つ。 |
| 師弟モード | 「あなたが弟子になるサクセスストーリー」。名前と姿を整え、現在弟子入りできる師匠6人を一画面で見渡す。選ぶたびに、その師匠から教わる能力と自分の初期値を隣で確認できる。 |

楼光では次の戦いに出る順番、弟子入りでは誰から何を学ぶかを、一度に読み取れるようにした。[楼光の編成](previews/tower-formation.jpg) ／ [師匠選び](previews/mentor-select.jpg)

## 師匠と過ごす道場

「修行を続ける」から前回の弟子に戻れる。別の記録で遊ぶときは「修行の記録を選ぶ」から、弟子名・師匠名・師匠の読みで探せる。記録は1ページ6件で、選んだ弟子の修行月、レベル、師匠との絆を再開前に確認できる。

道場の左には師匠の立ち絵とその月の一言、右には月・残り行動・修行・次の大会を置いた。台詞の名前を押すと師匠の詳細、下の自分の名前を押すと弟子手帳が開く。育成、能力変更、師匠との物語にも同じ位置に戻るボタンがある。[師弟ホームの実画面](previews/training-home.jpg)

## 通信対戦の卓

相棒を選んで相手を探す人は左の卓へ、友だちと遊ぶ人は右の「部屋を作る」「合言葉で参加」へ進む。合言葉は4文字。全角や小文字を貼り付けても使える。待合室では顔札と名前で席を確認でき、ホストの画面に空席のCPU切替と対局開始が出る。[通信対戦の入口](previews/online-menu.jpg) ／ [合言葉の待合室](previews/online-room.jpg)

マッチング中は相棒の一言とサーバーから届いた参加人数を表示する。順位表は今季の上位7人と自分の順位を並べて読む構成で、自分が8位以下でもその順位を確認できる。

## 今後キャラが増えたときのプラン

通常雀士の追加は名簿の件数とページに自動で反映される。次に確かめたいのは、繰り返し遊ぶ人が前回の相棒に戻る手間と、初見の人が二人の能力を比べるときの往復回数。プレイテストでこの二つを観察し、前者が多ければ「最近使った雀士」、後者が多ければ比較相手を一人固定できる表示を優先する。師匠が増えた場合は、教わる能力から探す絞り込みを優先する。

## 素材と確認

承認済みの空想曲線「ゲームUIセット vol.19」の同梱テーマを参照した。開始・着席には選択肢ボタン、手順と人物欄の切替にはタブ、ページ送りには左右の矢印、確認状態にはチェックを使う。PNGは原本を参照し、画像の配置・寸法・操作状態をHTMLとCSSで指定する。[素材クレジット](../CREDITS.md)

Chromeの一時プロフィールで、通常・ペア・団体の開局、相棒交代、師匠と能力の保存、修行完了の弟子を含む編成と出発を確認した。キャラ選択は1280×720、960×540、390×844の縦持ち回転表示で検証した。通信の名簿はローカルの画面テストで席の更新を再現し、待合室の同期は既存のローカルWebSocketテストでも確認した。

師弟では8件の記録を使った検索と再開、座学と休憩での残り行動の更新を確認した。通信ではローカル対戦サーバーに別の参加者を接続し、合言葉での入室、ホスト交代、CPU席の切替、開局、探索中の人数更新とキャンセルを確認した。順位表の上位・圏外・空・再読み込みには検証用データを使った。
